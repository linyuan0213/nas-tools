# 钉钉消息插件

钉钉消息渠道：支持**双向交互**（Stream 长连接接收用户消息）与**主动通知**（机器人单聊，精准发到个人）。

## 一、创建钉钉应用

1. 登录钉钉开发者后台 https://open-dev.dingtalk.com → 创建**企业内部应用**
2. 应用 → **凭证与基础信息**：记录 **AppKey / AppSecret**
3. 应用 → **应用能力** → 添加「**机器人**」（企业机器人）→ 配置名称/头像
4. 应用 → **事件与回调 → 事件订阅**：推送方式选 **Stream 模式**（无需公网回调地址），添加订阅事件「**机器人回调**」
5. **发布应用**（未发布则 Stream 连接被拒绝、机器人不可见）

## 二、参数获取

| 参数 | 获取位置 | 说明 |
|---|---|---|
| **App Key** | 应用 → 凭证与基础信息 | `ding...` 开头，Stream 交互 + 机器人单聊 |
| **App Secret** | 同上 | 与 AppKey 配套 |
| **AgentId** | 应用详情页 | 数字，仅群 Webhook 兜底时可能需要，非必须 |
| **机器人 Webhook** | 钉钉客户端 → 群 → 群机器人 → 自定义机器人 | 可选（通知兜底），需在钉钉群聊添加 |
| **接收人 userId** | 用户给机器人发消息自动记录；或应用有通讯录权限时 `topapi/v2/user/getbymobile` 按手机号查 | 主动通知接收人，建议在消息中心固定填写 |

## 三、消息中心配置

1. 启用「钉钉消息」插件 → 消息中心新增「钉钉」渠道
2. 填写：
   - **App Key / App Secret**：开放平台凭证（必填，交互 + 主动通知）
   - **通知接收人 userId**：固定填写你自己的 userId（交互时自动记录，但重启后以配置为准）
   - **交互**：选「是」（触发 Stream 长连接）
   - **机器人 Webhook 地址 / 加签密钥 / @手机号**：可选（仅群 Webhook 兜底时用）
3. 保存

## 四、验证

- 钉钉给机器人发「搜索 三体」→ 收到"正在处理"与搜索结果（交互）
- 勾选通知开关后，下载完成/站点统计等主动通知发到你的钉钉（机器人单聊，含海报图片）
