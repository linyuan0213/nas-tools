# 飞书消息插件

飞书消息渠道：支持**双向交互**（长连接接收消息 + 卡片按钮）与**带图通知**（海报随通知推送）。

## 一、创建飞书应用

1. 登录飞书开放平台 https://open.feishu.cn → 开发者后台 → 创建**企业自建应用**
2. 应用 → **凭证与基础信息**：记录 **App ID（`cli_...`）/ App Secret**
3. 应用 → **应用能力**：启用「**机器人**」
4. 应用 → **事件与回调**：
   - 订阅方式选 **WebSocket（长连接）**
   - 事件订阅添加「**接收消息 `im.message.receive_v1`**」（如需卡片按钮回调再加 `card.action.trigger`）
5. **发布应用版本**（未发布则无法接收消息）

## 二、参数获取

| 参数 | 获取位置 | 说明 |
|---|---|---|
| **App ID** | 应用 → 凭证与基础信息 | `cli_...` 开头，应用凭证 |
| **App Secret** | 同上 | 与 App ID 配套 |
| **通知接收人 open_id** | 用户给机器人发消息后，事件日志 `sender.sender_id.open_id`；或应用有通讯录权限时 `contact/v3/users/batch_get_id` 按手机号/邮箱查 | 主动通知接收人 |
| **群 chat_id** | 把机器人拉进群发消息，事件 `message.chat_id`（`oc_...`） | 主动通知发到群 |
| **机器人 Webhook** | 群 → 群机器人 → 自定义机器人 | 可选（Webhook 模式仅通知） |

## 三、消息中心配置

1. 启用「飞书消息」插件 → 消息中心新增「飞书」渠道
2. 填写：
   - **App ID / App Secret**：开放平台凭证（必填，应用模式 = 交互 + 通知）
   - **通知接收人**：你的 open_id（`ou_...`）或群 chat_id（`oc_...`），逗号分隔
   - **交互**：选「是」（应用模式下长连接随应用凭证自动启动）
3. 保存

> 应用模式与 Webhook 模式：填了 App ID/Secret 即应用模式（交互 + 通知）；只填 Webhook 地址则 Webhook 模式（仅通知，不支持交互）。

## 四、验证

- 飞书给机器人发「搜索 三体」→ 收到卡片列表，点「选择」按钮可交互（搜索/订阅/下载/分页）
- 勾选通知开关后，下载完成等事件通知含海报图片推送到飞书
