# 全量配置清单（大白话版 · 无需懂任何格式）

> **怎么用**（非常简单）
> 1. 在下面相应小节的"⬇ 填写区"里，**用平常说话的方式**写上你要改的内容；
> 2. 不会写/懒得写就直接给 Agent 一句话，比如：`把 1 号下载器密码改成 xxx 并设为默认`；
> 3. 整篇发给「消息中心 → AI 助手」→ Agent 会把你的大白话整理成逐条改动，列给你确认 → 一次执行 → 逐项告诉结果。
>
> 看不懂的字段问 Agent 就行（如"下载器 id 是多少？"会让它先查给你）。
> ⚠️ 密码/Token 会出现在消息里，请妥善保存勿外发；Agent 回显永远是 `***`。

**大白话格式参考（照样子把值换掉即可）：**

```
下载器：id=1，地址 192.168.1.10，端口 8889，用户名 admin，密码 xxxxxx，启用，设为默认
新增一个 qBittorrent 下载器：名称=QB主库，地址 192.168.1.10，端口 8889，用户名 admin，密码 xxxxxx
```
