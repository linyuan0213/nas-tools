# Agent 配置助手说明

在 **消息中心 → AI 助手**（或已接入的 Telegram / Webhook 渠道）中，可以直接让 Agent 帮你完成系统配置。所有写操作 Agent 都会先列出改动，待你确认后才执行；敏感值（密码/Token/Key）回显一律为 `***`。

## 三种用法

1. **对话式向导（最省心）**：直接说"帮我配置系统"，Agent 会按顺序（下载器 → 消息通知 → 媒体服务器 → 索引器 → 插件 → 目录同步 → 媒体库目录 → 刮削/常规）**一次只问一个必填字段**，你说"跳过"就换下一项，配完自动小结。
2. **单项一句话**：如"把 qBittorrent 的密码改成 xxx""新增 Telegram 通知：token=…、chat_id=…""Emby 换成 192.168.1.20 并设为默认"。缺字段时 Agent 会追问。
3. **批量清单**：要一次配多项时，把 `docs/agent-config-manifest.template.md`（大白话清单）填好后整篇发过去，Agent 会一次确认并逐项报告。

## Agent 能配置的范围

| 类别 | 说明 |
|------|------|
| 下载器 | 改连接（地址/端口/账号密码）、启停、设默认 |
| 消息通知 | 新增/修改/删除渠道（Telegram、Server酱、企业微信、Bark、Webhook 等） |
| 媒体服务器 | Emby/Jellyfin/Plex/飞牛 连接、启用、设默认 |
| 索引器 | 内置/Jackett/Prowlarr 等 启停与连接 |
| 插件 | 启用/禁用、更新配置 |
| 目录同步 | 新增/修改同步任务（复制/硬链接/软链接/移动）、查看存储后端 |
| 媒体库目录 | 电影/剧集/动漫/未识别 分类目录 增删 |
| 刮削 | 元数据/图片开关 |
| 系统常规 | 保存目录、语言、整理方式、搜索等（`app/media/pt/subscribe/laboratory` 节点） |
| 诊断 | 查最近日志/历史日志、状态类只读工具 |

## 安全与边界

- 需要**对应权限**（默认 admin 全权限）。
- 密码/Token/密钥类**只写不读**：Agent 回显永远是 `***`，且不会因对话而泄露。
- `security`、`database`、`log` 及密码类系统配置**不允许 Agent 修改**（请走界面）。
- 新增"存储后端"实例、账号/角色、分类规则、媒体库路径监控等暂未开放给 Agent（界面操作）。
- 所有改动以 Agent 列出的"待确认清单"为准，确认后才写入。

> 更细的可视化配置仍在 **系统设置** 页面完成；本助手适合日常调整与快速初始化。
