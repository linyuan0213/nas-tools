# 常见问题

## 安装部署

### Q: Docker 启动后无法访问前端？
检查端口映射：
```bash
docker compose ps
```
前端默认映射 `8080:8080`，后端 `3000:8080`。访问 http://localhost:8080。

### Q: 首次登录失败？
默认账号：
- 用户名: `admin`
- 密码: `password`

若修改过密码但遗忘，需删除 `config/user.db` 重置（会丢失用户数据）。

### Q: 配置文件修改后未生效？
后端使用 `watchdog` 监控配置文件变更，但部分配置需重启服务生效。建议修改后观察日志或重启容器。

## 媒体识别

### Q: 无法识别媒体？
1. 检查 **设置 > 基础设置 > 媒体** 中 TMDB API Key 是否配置
2. 检查网络是否能访问 `api.themoviedb.org`
3. 尝试开启 **实验室 > 辅助识别** 或 **WEB增强识别**

### Q: 电视剧集数识别错乱？
开启 **设置 > 基础设置 > 媒体 > 启用集数映射**，可在媒体详情页手动调整集数映射关系。

## 下载与转移

### Q: 下载完成不自动转移？
1. 下载器配置中是否开启「监控」
2. 检查下载器设置的「保存目录」与「媒体库目录」是否在同一个磁盘（硬链接需求）
3. 查看日志中是否有转移失败的错误信息

### Q: 硬链接失败？
硬链接要求源目录和目的目录在同一磁盘分区。Docker 环境下需映射上级目录：
```yaml
volumes:
  - /data:/data  # 统一定上级目录
```

### Q: 目录同步不触发？
1. 检查宿主机 inotify 限制：
   ```bash
   echo fs.inotify.max_user_watches=5242880 | sudo tee -a /etc/sysctl.conf
   sudo sysctl -p
   ```
2. 网盘/SMB 不支持实时通知，需开启目录同步的「兼容模式」或使用「下载器监控」

## 站点

### Q: 站点无法连通？
1. 检查 Cookie 是否有效（过期需更新）
2. 检查代理设置是否正确
3. 使用「站点连通性测试」排查具体错误

### Q: 馒头(M-Team)怎么配置？
在站点维护中添加请求头：
```json
{"x-api-key": "你的令牌"}
```
令牌在馒头控制台 > 实验室 > 存取令牌获取。

### Q: 肉丝(Rousi)怎么配置？
在站点维护中添加请求头：
```json
{"Authorization": "Bearer 你的Passkey"}
```
Passkey 在肉丝账户设置中复制。

## 刷流

### Q: 刷流任务下载了非免费种子？
检查任务配置中的「促销」选项：
- 选择「全部」不过滤促销类型
- 状态图标为绿色时才表示仅下载 FREE 种子

### Q: 刷流任务添加后没反应？
1. 检查任务状态是否为「运行中」
2. 检查执行周期是否正确（支持 cron 表达式）
3. 查看任务详情中的「种子列表」确认是否有下载记录

### Q: 配置了「下载等待时间」很久了种子还不删？
「等待时间」统计的是种子**进种时长**（自添加起算），适用于排队/等待（Pending、Queued）状态的种子。若种子处于「正在下载」或已做种状态，等待时间规则不生效；请确认：
1. 种子状态确为等待中（下载器中被限速排队、无做种/下载进度）
2. 规则模式为「或」时需任一条件满足，「与」模式需全部满足
3. 删除条件同时配置了其他规则时，检查其他条件是否未满足

### Q: 设置了「做种数优先」却下载了做种数少的资源？
1. 做种数优先只对**做种数不同**的结果生效；做种数相同时按站点优先级决定
2. 确认索引器确实返回了做种数（外置 Jackett/Prowlarr 部分站点可能不返回）
3. 确认站点优先级已配置（索引器优先级继承站点维护中的站点优先级）

## 消息中心（AI 助手）

### Q: 中文输入法按回车直接发送消息？
已修复：输入法组合状态下的回车（确认候选词）不会触发发送，只有普通回车才发送。

### Q: 知识库检索无结果？
1. 确认 Agent 已启用并配置了 Embedding，然后在知识库页面点击「重建索引」
2. 确认 Embedding 使用的是专门的向量模型（如 `nomic-embed-text`、`bge-m3`），对话模型（如 `qwen2.5:0.8b`）不能用于 Embedding
3. 查看系统日志中是否有向量化/检索错误

## 近期下载

### Q: 点击「复制链接」提示复制失败？
复制功能优先使用浏览器剪贴板 API，在**非安全上下文**（通过局域网 IP 的 http 访问）或浏览器剪贴板权限被拒时自动降级为兼容方案。若仍失败：
1. 使用 https 或 localhost 访问
2. 检查浏览器是否禁止了站点剪贴板权限

## 通知

### Q: Telegram 通知收不到？
1. 检查 Telegram Bot Token 和 Chat ID
2. 如果使用 Webhook，确保外网可访问并配置正确的域名
3. 检查该通知渠道的 [交互安全 IP 白名单](notifications.md#交互安全ip-白名单) 是否放行了 Telegram 来源 IP

### Q: 消息模板不生效？
1. 检查 JSON 格式是否正确
2. 确认消息类型名称拼写正确
3. 查看系统日志是否有模板渲染错误

## 性能

### Q: 内存占用过高？
1. 降低 RSS 订阅频率
2. 关闭不必要的站点数据统计
3. 减少同时运行的刷流任务数量

### Q: 磁盘空间不足？
刷流任务中可配置「磁盘剩余空间」删种规则，低于阈值时自动删除种子释放空间。
